1. Chart and table

Columns: Label · Value · Type (Plan, Actual, Forecast, Step) · Group (optional). Leave the last total blank to compute it.

Long table, header row required: Entity (Channel, Market…) · Period · AC · FC · PL. One panel per entity (2 to 9), all on the same scale.

One row per period: Period · AC · FC · PL. Fill AC for past periods and FC for future ones (never both). PL is optional but needed for variances.

2. Chart

Orientation
Numbers
Colour and checks Steps within ± this % of the start total stay grey. 0 to 50; 0 colours every step. Variances within ± this % of plan stay grey. 0 to 50; 0 colours every variance.
Columns Charts with the same name use one scale, so bar lengths compare across them. Each shows the same grey scale bar.
Arrows and brackets Difference arrow between any two bars, or a bracket with the subtotal of a run of bars. They follow the bar names, so they survive edits.
